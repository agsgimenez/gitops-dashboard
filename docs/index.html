Features

Everything you need, nothing you don't

Built for engineers who manage multiple repos and want visibility without leaving the browser.

🏢

Multi-org workspace switcher

Full-screen org selector with real GitHub avatars. One click to switch context across all your organizations and personal accounts.

▶

Workflow dispatch

Trigger workflow_dispatch jobs with inputs parsed automatically from the YAML file. Only runs what your token permits.

🔀

PR Board

Open pull requests across all repos with live check run status, reviewer requests, labels, and draft state — updated in real time.

🔑

Env Manager

Read, create, edit and delete GitHub Environment variables. Secrets are listed by name. Compare against .env.example to spot missing vars.

🔔

Browser notifications

Get a native OS notification the moment a running workflow completes — success or failure — while you work in other tabs.

📋

Run history

Expand any workflow to see the last 10 runs with status, duration, actor, branch, and a direct link to GitHub.

Security

Your token, your permissions, your control

GitOps Dashboard only performs the actions allowed by your GitHub token's scopes. Every API call goes directly from your browser to GitHub — no proxy, no server, no middleman.

  • ✓Token stored in browser localStorage only — never written to any file
  • ✓No telemetry, no analytics, no third-party scripts
  • ✓Fully open source — audit every line before running
  • ✓Dispatch actions are gated by the token's workflow scope
  • ✓Secret values are never readable — names only, via the GitHub API

Setup

Running in 3 steps

No npm install. No Docker. No server. Just a file and a token.

1

Clone the repo

Download or clone gitops-dashboard to any folder on your machine.

2

Add your repos

Copy config.example.js to config.js and list your repos. No PAT in the file — it's entered once in the UI.

3

Open the file

Double-click index.html or run start index.html. Paste your PAT once and it's stored in your browser.

Pure HTML. Pure JavaScript. Pure speed.

No framework. No bundler. No runtime. Ships as a handful of files you can read in full.
